
# 📊 GMC - Grade Manager

**GMC** (Grade Manager) is a web-application designed for **faculty and students** to manage academic marks with smart grading logic. It supports mark entry, mark viewing, and intelligent bonus allocation based on extracurricular activities.

---

## Purpose

GMC streamlines academic performance management by enabling:
- **Faculty** to input and manage internal marks
- **Students** to view their own marks
- **Bonus allocation** based on extracurriculars to **maximize grades** using an algorithmic approach

---

## Tech Stack

- **Frontend**:
  - [React](https://reactjs.org/)
  - [Bootstrap](https://getbootstrap.com/)

- **Backend**:
  - [Node.js](https://nodejs.org/)
  - [Express.js](https://expressjs.com/)
  - [MongoDB](https://www.mongodb.com/)
  - [Mongoose](https://mongoosejs.com/)


---

## Features

- Faculty dashboard to enter and update subject-wise marks
- Student dashboard to securely view their own grades
- Bonus marks awarded for extracurriculars like competitions, projects, etc.
- Algorithm intelligently applies bonus to maximize overall subject grades
- Role-based access for faculty and students
- Export grade reports and summaries

---

## Bonus Allocation Logic

The backend contains logic that:
- Takes extracurricular points earned by the student
- Evaluates how bonus can be **strategically distributed across subjects**
- Ensures **maximum grade improvement** while respecting grade boundaries and subject limits
